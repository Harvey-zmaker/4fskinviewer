# Viewable 4D Skins

Paper 26.2 plugin that lets players wear 4D skins (via FreeMinecraftModels) visible to Java and Bedrock players.

Requires on the server: FreeMinecraftModels, ResourcePackManager, Floodgate, Geyser.

Commands: /skin <name>, /skin list, /skin off, /skin reload (admin)

Build: push to GitHub, open the Actions tab, download the Viewable4DSkins artifact.
